# Little Empires - Colony Manager

This is a tool to manage colonies in Star Wars RPG according to the rules under docs.

## Requirements

* Colonies are organised by their homeworld

## Suggestions

Stack should be free. Only two people will be using this tool.
The frontend will be hosted in github pages, and the shared data will be in 
google drive, accessed via google login, the data file directory will be shared 
on google drive.
